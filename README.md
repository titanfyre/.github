# titanfyre project support and contribution guides

Shared defaults for repositories without their own policy files. Individual repository policies, release prerequisites and licences take precedence.

- [Get support](SUPPORT.md): report versions, reproducible steps and the observed result.
- [Contribute](CONTRIBUTING.md): focused changes, actual test evidence and preserved attribution.
- [Report a security concern](SECURITY.md): use the affected repository's private reporting channel where available.
- [Choose a project](https://github.com/TitanCSA/TitanCSA/blob/main/PROJECTS.en.md): applications, SDKs and documented first runs.

These files do not change product licences, guarantee a response time or certify a release. Project-specific instructions override the defaults. Issue/PR templates are in `.github/`.

Documentation maintained with AI assistance and checked against GitHub's default community-file behavior.
